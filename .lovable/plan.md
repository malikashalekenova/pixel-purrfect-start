## Цель

Когда игрок впервые встречает Пушка, открыть экран создания персонажа. После нажатия «Начать историю» создаётся аккаунт и профиль игрока в базе, появляется анимация «Профиль создан», игрок возвращается ровно туда, где остановился разговор, и Пушок произносит финальную реплику. Дальше профиль автоматически обновляется при важных событиях, а игрок может в любой момент открыть его через меню компьютера дома.

## Что меняется

### 1. База данных (миграция)

Расширяю таблицу `profiles` новыми полями:

- `display_name` — имя, выбранное игроком
- `fur_color` — цвет шерсти (orange / cream / gray / black)
- `eye_color` — цвет глаз (green / blue / amber / violet)
- `clothing` — стартовая одежда (hoodie / jacket / sweater)
- `coins` (по умолчанию **50**)
- `reputation` (по умолчанию **0**)
- `level` (по умолчанию **1**)
- `gang` (текст, по умолчанию пусто)
- `gang_leader` (boolean, по умолчанию false)

`contracts_completed`, `xp`, `total_earned`, `username` — уже есть. Триггер автосоздания профиля обновляю так, чтобы новые игроки сразу получали 50 монет и 1 уровень.

### 2. Создание персонажа (новый компонент)

`CharacterCreation.tsx` — модалка, открывается после первого диалога с Пушком. Поля:

- имя персонажа
- цвет шерсти (4 свотча)
- цвет глаз (4 свотча)
- стартовая одежда (3 варианта)
- email + пароль (для сохранения прогресса)

Кнопка **«Начать историю»**: регистрирует игрока (email/password), записывает выбранные параметры в `profiles`, показывает анимацию «Профиль создан», закрывает модалку.

Заметка: Google-логин в этом шаге добавлять не буду, чтобы не раздувать форму; могу подключить отдельно по запросу.

### 3. Возврат к Пушку

После закрытия модалки игрок снова видит ту же улицу с Пушком на прежнем месте. Над ним всплывает реплика **«Надеюсь, тебе понравится в нашем городе!»**, после которой управление возвращается полностью.

### 4. Автосохранение

Создаю утилиту `useProfileSync` / `updateProfile(patch)`, которая записывает изменения в `profiles` при:

- завершении контракта (`+coins`, `+xp`, `+contracts_completed`)
- знакомстве с важным NPC (для начала — Пушок, Рыжик)
- покупке одежды (заглушка под будущую механику)
- повышении уровня (по порогам XP)

Все изменения идут через единый хук, чтобы потом было легко добавлять события.

### 5. Профиль в меню компьютера

В `Desktop.tsx` добавляю иконку **«Профиль»**, которая открывает окно с текущими значениями всех полей таблицы. Доступно в любой момент, когда игрок дома за компьютером.

## Технические детали

```text
src/
├── components/
│   ├── CharacterCreation.tsx   (новый — форма + signUp + insert profile)
│   ├── ProfileWindow.tsx       (новый — просмотр профиля в Desktop)
│   ├── Street.tsx              (показывает CharacterCreation после Пушка,
│   │                            затем финальную реплику)
│   └── Desktop.tsx             (новая иконка "Профиль")
├── lib/
│   └── profile.ts              (новый — getProfile, updateProfile, level math)
└── routes/index.tsx            (хранит currentProfile, прокидывает в Street/Desktop)
```

Миграция расширяет `profiles` через `ALTER TABLE ... ADD COLUMN`, не ломая существующие записи. RLS уже корректный (читают все — для рейтинга; пишет только владелец).

## Что НЕ входит в этот план

- Google / Apple вход (можно добавить отдельно).
- Полноценный экран входа для возвращающихся игроков (пока — только регистрация при первом знакомстве с Пушком; форма логина — следующий шаг).
- Магазин одежды, система банд — только поля в БД, UI позже.
